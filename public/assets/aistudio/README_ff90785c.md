# Wonderart design reference package
Native Android: Kotlin, Jetpack Compose, MVVM. Firebase Authentication, Firestore, Cloud Storage for artwork, Cloud Functions for privileged operations. Zoom Meeting SDK for online classes only. No recording, YouTube, recorded playback or physical attendance. Include four sample courses and four clearly marked demo community posts. Use demo enrollment until payment integration is configured.

Use the screenshots as visual references: purple primary, coral accent, pale lavender background, rounded cards, outline icons and central plus button. Replace Sketchroom with Wonderart and teacher with Nikhil. Adapt layouts to courses, community and live classes. Do not copy teacher self-registration. Admin role must be assigned securely.

Creative Canvas: free for all registered students, independent of course enrollment. Native Compose Canvas with touch/stylus drawing, pencil, brush, marker, eraser, color picker, fill, shapes, brush size, opacity, undo/redo, layers, zoom/pan, background color and clear confirmation. Save drafts locally, work offline, export PNG and publish to community using Firebase with user confirmation. Central plus button offers Create a Drawing and Upload Artwork. Navigation: Home, Courses, Create, Community, Profile; live classes accessible via dashboard and courses.

These are screenshots, not original editable Figma frames or extracted design tokens. Colors and spacing must be estimated visually unless original Figma access is provided. Logo is a separately generated brand asset. No application source code is included.
